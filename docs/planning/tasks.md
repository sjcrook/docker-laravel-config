# Tasks

Task IDs use `S<2-digit sprint>` / `T<3-digit task>`, assigned sequentially and never reused or renumbered. Each original epic is represented as one sprint. Every task row starts with `| S.. | T.. |`, so task-tracking scripts can identify rows consistently.

**Status values:** 🔲 Todo · 🔄 In Progress · YYYY-MM-DD (note) · ✅ Done · YYYY-MM-DD · ⛔ Blocked · <reason>

**Forward test dependency:** if a task's test can only pass once a later task is implemented, leave it `🔄 In Progress · YYYY-MM-DD (depends on T0XX)` until that task is implemented, then return and finish it. Record the pair in `docs/handoff.md`'s "Next" section.

**Blocking questions:** a question that blocks only one task is that task's blocker: mark it `⛔ Blocked · <reason>`. A question that blocks all further work is a project-wide blocker: mark the next task to be worked `⛔ Blocked · <reason>` too.
